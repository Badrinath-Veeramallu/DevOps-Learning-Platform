
# DevOps Learning Platform

A learning platform for DevOps concepts, built as a team project.

## Technology Stack

- Frontend: React
- Backend: Node.js and Express
- Database: MongoDB
- Mobile application: Flutter (planned)

## Project Structure

- `web/` - React web application
- `server/` - Express API and backend logic
- `mobile/` - Flutter application (planned)
